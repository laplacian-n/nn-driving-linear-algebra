# 2D Self-Driving Car Neural Network (Linear Algebra Project)

Neural-network drivers evolved with a genetic algorithm on procedurally generated,
F1-like (scaled) circuits, with a dynamic bicycle model and Pacejka tyres.
The project studies how much perception and how large a network a driver needs,
and how far a trained network can be compressed.

- `racing/` – simulator core (track generator, physics, sensors, networks, GA)
- `experiments/` – experiment runner and configs
- `app/` – training viewer and demo app
- `analysis/` – figures and statistics
- `docs/` – experiment plan, deliverables plan
- `legacy_v1/` – the first version of the project (point-mass physics), kept for reference

Work in progress.
