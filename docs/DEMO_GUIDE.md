# คู่มือ demo ให้เพื่อนทดสอบ (≥ 10 ตัวอย่าง, ≥ 2 คน)

## ข้อกำหนดของอาจารย์หมายถึงอะไร

ตอนนำเสนอต้องให้ **เพื่อนอย่างน้อย 2 คน** มาลองใช้โปรแกรมเอง โดย **เลือกข้อมูลที่จะป้อนเข้าโครงงานเอง** รวมกันอย่างน้อย **10 ครั้ง**
"ข้อมูลที่นำเข้า" ของโครงงานนี้คือ **สนาม** (สุ่ม / กำหนด seed / วาดเอง), **ระดับความยาก** และ **โมเดล** ที่จะให้ขับ
ผลลัพธ์คือรถขับจบรอบไหม ไปได้กี่ % ของสนาม เวลาต่อรอบ และความเร็วเฉลี่ย ซึ่งโปรแกรมบันทึกให้อัตโนมัติ

## วิธีทำ

1. เปิดโปรแกรม: `python -m app.demo`
2. ให้เพื่อนพิมพ์ชื่อตัวเองในช่อง 1 (ใช้แยกผลรายคน)
3. ให้เพื่อนเลือกเองในช่อง 2–4 แล้วกด Start ดูรถขับ จบแล้วกล่องผลจะขึ้นและบันทึกให้
4. ทำจนครบ ~5–6 ครั้งต่อคน (รวม ≥ 10 ครั้ง)
5. หลังจบ: `python analysis/demo_summary.py` → ตารางสรุปรายคน / รายโมเดล + `figures/demo_results.png` ใส่สไลด์

ผลทั้งหมดอยู่ใน `data/demo_results.csv` (เวลา, ชื่อผู้ทดสอบ, โมเดล, ที่มาของสนาม, seed, ความยาก, ความยาวสนาม, จบรอบไหม, % ที่ไปได้, เวลาต่อรอบ, ความเร็วเฉลี่ย)

## เตรียมก่อนวันนำเสนอ

- ลองเปิดโปรแกรมบนเครื่องที่จะใช้จริง 1 ครั้ง (ครั้งแรก Numba คอมไพล์ราว 10–20 วินาที)
- ลบ `data/demo_results.csv` ของการซ้อมทิ้งก่อนเริ่มเก็บผลจริง (หรือเก็บไว้แยกไฟล์)
- ถ้าเวลาน้อย: สนามระดับ 0.5–1.0 จบรอบเร็วกว่า (~40–60 วินาที/รอบ) ส่วน Esc ระหว่างขับจะกลับเมนูโดยไม่บันทึกรอบนั้น
