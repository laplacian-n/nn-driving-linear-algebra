## 3. ส่วนข้อมูล (หัวข้อ 2–3 ของรายงาน): ออกแบบให้มีขั้นตอนข้อมูลจริง

ข้อมูลทั้งหมดได้จากการจำลอง เนื้อหาส่วนนี้จึงต้องเป็น **pipeline จริงที่โค้ดทำงานผ่าน** ไม่ใช่ขั้นตอนที่แต่งขึ้นมาให้ครบหัวข้อ

### 3.1 ชุดข้อมูลหลัก: Driving Sensor Dataset
- **วิธีเก็บ:** ตัวควบคุมอ้างอิงขับสนามชุด C (10 สนาม) โดยใส่การรบกวนแบบสุ่ม (สุ่มเบี่ยงพวงมาลัยหรือความเร็วเป็นช่วง ๆ) เพื่อให้ข้อมูลครอบคลุมสถานะใกล้กำแพงและสถานะฟื้นตัว ไม่ใช่แค่เส้นทางที่สมบูรณ์แบบ
- **เซนเซอร์:** มีแบบจำลองความผิดพลาดของเซนเซอร์ระยะที่เกิดจริง
  - noise ±2%
  - **ไม่มีการสะท้อนกลับ (no return)** เมื่อเกินระยะ จะอ่านได้ที่ระยะสูงสุด
  - **dropout** อ่านค่าผิดเป็น 0 ด้วยความน่าจะเป็นต่ำ
- **หนึ่งตัวอย่าง (แถว):**
  - เวลา, track id, ความยาก, ความคืบหน้า
  - ระยะรังสี 17 ค่า
  - vx, vy, yaw rate, มุมล้อ
  - คำสั่ง 4 ค่าของตัวควบคุม
  - ประเภทช่วงถนน (ทางตรง / โค้งเร็ว / โค้งช้า / hairpin ตามรัศมีความโค้ง)
  - สถานะ (ปกติ / ชน / หลังชน)
- **ขนาดคาดการณ์:** 10 สนาม × ~40 s × 30 Hz × หลายรอบ ≈ 10,000–30,000 แถว (เงื่อนไขขั้นต่ำ 150 ชุด)

### 3.2 สถิติเบื้องต้น
- ทุกตัวแปร: count, mean, SD, min, max, ร้อยละที่หายหรือผิด
- **สัดส่วน (%) ตามรูปแบบข้อมูล:**
  - ตามประเภทช่วงถนน
  - ตามช่วงความเร็ว
  - ตามการกระทำ (เร่ง / เบรก / ปล่อย / แฮนด์เบรก)
  - ตามประเภทค่าของรังสี (ปกติ / ระยะสูงสุด / dropout)

### 3.3 การ Clean

| กลุ่ม | เงื่อนไข | การจัดการ |
|---|---|---|
| สมบูรณ์ | ทุกค่าถูกต้อง | ใช้ตามเดิม |
| ต้องแก้ไข | รังสี dropout (อ่าน 0 ขณะรถยังอยู่บนถนน) | แทนด้วยค่าจากรังสีข้างเคียงและก้าวก่อนหน้า (median) |
| ต้องแก้ไข | รังสีที่ไม่มีการสะท้อนกลับ (= ระยะสูงสุด) | ทำเครื่องหมายว่า censored แล้วใช้ log encoding ที่จำกัดค่าไว้ |
| ตัดทิ้ง | แถวหลังชนหรือรถออกนอกถนน | ตัด |
| ตัดทิ้ง | v_x < 5 m/s (ช่วงความเร็วต่ำที่แบบจำลองผสม kinematic) | ตัด |
| ตัดทิ้ง | NaN/inf, แถวซ้ำ, ช่วงเริ่มต้น 0.5 s แรก | ตัด |

### 3.4 ผลก่อน/หลัง
- histogram ของระยะรังสีก่อน/หลัง (dropout ทำให้มีแท่งผิดปกติที่ 0)
- ตารางสถิติก่อน/หลัง
- **eigenvalue และ eigenvector ของ PCA ก่อน/หลัง clean** เป็นผลที่วัดได้ว่า dropout บิด covariance และทำให้ PC เพี้ยน

### 3.5 ชุดข้อมูลรอง: ผลการทดลอง
- ทุก run (~150 แถว) และผลรายสนามของทุกการประเมิน (หลายหมื่นแถว)
- ใช้ทำสถิติผลลัพธ์ในหัวข้อผลการทดลอง

## 4. แอป Demo (สำหรับให้เพื่อนทดสอบ ≥ 10 ตัวอย่าง, ≥ 2 คน)

**สิ่งที่ผู้ทดสอบป้อนเข้าโครงงาน:**
1. **สนาม:** เลือก seed เอง สุ่ม หรือ **วาดสนามเองด้วยเมาส์** แล้วระบบแปลงเป็นเส้นโค้ง Bezier
2. **ความยาก:** 0–1
3. **โมเดล:** เลือกจากผลการทดลอง เช่น เซนเซอร์ 3 เส้นกับ 17 เส้น, โมเดลเล็กกับใหญ่, ก่อน/หลังบีบอัด

**สิ่งที่แสดงและบันทึก:**
- หน้าจอแสดงกล้องตามรถ แผนที่ย่อ เส้นทางระบายสีตามความเร็ว และข้อมูลสำคัญเท่านั้น
- ทุกการทดสอบบันทึกลง `demo_results.csv` อัตโนมัติ (ชื่อผู้ทดสอบ, สนาม, โมเดล, จบรอบไหม, เวลา)
- ตารางผลนี้นำไปใส่สไลด์ได้เลย

**ส่วนเสริม (ถ้าเวลาเหลือ):** โหมด "แข่งกับ AI" ให้เพื่อนขับเองด้วยคีย์บอร์ดเทียบเวลาต่อรอบ
